### Etapa IV - Consultas y Casos de Uso

En esta etapa se desarrollan y prueban consultas SQL sobre la base de datos Energy, con el objetivo de obtener información relevante para la gestión del sistema. Se incluyen consultas de facturación, reportes agregados de ventas y consultas avanzadas mediante relaciones entre tablas, funciones de agregación y filtros condicionales.

- [Ver carpeta en `main`](https://github.com/NairN23/Energy-BD-equipo45/tree/main/ETAPA_IV/sql/consultas)
- [Ir a rama `ETAPA_IV`](https://github.com/NairN23/Energy-BD-equipo45/tree/main/ETAPA_IV)

### Etapa V - Programación y Administración de Base de Datos

En esta etapa se implementan funcionalidades avanzadas de SQL Server para mejorar la automatización, integridad, seguridad y rendimiento de la base de datos del sistema Energy.

Se incluyen procedimientos y funciones almacenadas, manejo de transacciones, triggers de auditoría, administración de usuarios, roles y permisos, e implementación de índices.
